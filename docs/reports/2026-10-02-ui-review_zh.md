# UI 评审 — 2026-10-02

[English version](2026-10-02-ui-review.md)

本记录描述库页面与响应式布局优化后的 PureTerm 共享界面。当前取值与行为以[设计系统](../design-system_zh.md)为准。评审日期：2026 年 10 月 2 日，Asia/Shanghai。

## 范围与观察

浏览器检查覆盖 1440px 桌面下深色与浅色的 Hosts 空状态、表格、卡片及连接编辑器；在 820、620、390 和 360px 宽度下检查了布局及页面溢出。检查包含英文与中文。通过本地 SSH 测试服务检查已连接终端的文件与监控面板，并检查了 Keychain 空状态及编辑器。截图保存在仓库外的本地目录。

| --- | --- |
| 排版 | 库页面标题在宽于 620px 时为 28px，更窄时为 24px；元数据保持次要层级。界面文字使用随包 Inter 和系统回退，地址及密钥指纹使用等宽字体 token。检查了两种语言的换行与截断。 |

## 评审中修复的问题

- 主机和 SFTP 的悬停操作可能盖住元数据。两者现有独立操作列；SFTP 也补充了翻译后的列标题及路径输入框名称。
- 窄屏编辑器曾依赖由内容决定高度的工作区。外壳现在保留确定高度的网格轨道，覆盖式编辑器打开时，底下的库控件退出键盘焦点顺序。
- 独立评审发现固定面板高度可能裁切移动端的终端与工具分栏。该布局在最终浏览器回归前已修正。
- 独立评审发现切换主题或密度可能重置视图切换按钮的标签。视图控件现在使用随当前视图更新的翻译映射。后续冷启动检查又发现，已保存中文偏好时部分可访问标签仍为英文；在渲染动态控件前先应用语言，修正了初始化顺序。最终生命周期回归包含冷启动断言。

- 后续测试复现了两个会话面板问题：收起自定义分栏后内联轨道仍然生效，实时缩放跨过 820px 时也会留下旧的网格轴与分隔条方向。收起现在会清除两条轴并保留标签比例；受作用域管理的媒体查询监听更新布局轴，指针移动也即时检查方向，避免断点事件尚未到达时沿用旧轴。回归检查保持同一 SSH 会话和 xterm 实例，保留面板焦点，验证终端自动适配，并使用真实指针捕获跨过断点。
