# UI Review — 2026-10-02

[中文版本](2026-10-02-ui-review_zh.md)

This dated record covers the shared PureTerm interface after the library and responsive-layout refinement. Current values and behavior belong in the [design system](../design-system.md). Review date: October 2, 2026, Asia/Shanghai.

## Scope and observations

Browser inspection covered the 1440px desktop Hosts library in dark and light themes: empty state, table, cards and connection editor. Widths of 820, 620, 390 and 360px were checked for layout and page overflow. English and Chinese were inspected. A local SSH fixture exercised a connected terminal with Files and Monitor; Keychain's empty state and editor were also inspected. Screenshots are retained locally outside the repository.

| Dimension | Design and review evidence |
| --- | --- |
| Typography | Library titles use 28px above 620px and 24px below; metadata stays subordinate. Interface text uses the bundled Inter family and system fallbacks. Addresses and key fingerprints use the monospace token. Both languages were inspected for wrapping and clipping. |
| Whitespace | Both libraries share responsive page gutters, a 104px minimum header, 48px comfortable / 34px compact rows and 360px docked editors. Card interiors and empty-state copy have room distinct from the denser tables. Desktop and narrow layouts were inspected. |
| Visual hierarchy | The title, primary creation action, search and view switch have separate roles. Selected rows have an accent edge and fill. Hosts keep Connect visible; each action occupies its own column. Empty and filtered states provide the next action. |
| Color | The existing neutral surfaces, blue accent and semantic status tokens remain shared by dark and light themes. No new palette or external artwork was introduced. Both themes were inspected, and the existing token/contrast checks passed as part of `npm run verify`. |
| Motion | Controls use 160ms transitions; editors enter over 240ms; the empty-state diagram enters once over 600ms. With reduced motion enabled, the browser reported an editor animation duration of 0.01ms. Toasts and skeletons have explicit overrides. |
| Microinteractions | Connect, Edit and Delete have accessible names; selection exposes `aria-pressed`. Clear search returns focus to search. Search focus, selected view controls, full-text tooltips and hover states were reviewed. Narrow overlay editors hide underlying library controls from keyboard focus. |
| Responsiveness | Library columns respond to their own panel width. Mobile uses a 48px top bar plus 48px horizontal navigation. Editors fill the available workspace; SFTP keeps file names and actions when narrow. No page overflow was observed at the inspected widths. The browser layout regression passed 188 measurements across 18 cases plus a continuous resize and pointer-drag sequence. |
| Originality | The visual direction follows the SSH workflow: a local terminal-to-server diagram, restrained technical metadata, and distinct library and session layouts. The diagram is inline SVG drawn for this interface and uses its existing tokens. |

## Findings corrected during review

- Host and SFTP hover actions could cover metadata. Both now have reserved action columns; SFTP also has translated column headings and a named path input.
- Narrow editors previously depended on content-sized workspace geometry. The shell now keeps a definite grid track, and covered library controls are removed from keyboard focus while an overlay editor is open.
- Independent review found that a fixed panel height could clip the mobile terminal/tool split. The layout was corrected before the final browser regression run.
- Independent review found that changing theme or density could reset view-switch labels. View controls now use translation mappings that track the selected view. A later cold-start check found English accessible labels with a saved Chinese preference; applying the locale before rendering dynamic controls corrected that initialization order. The final lifecycle rerun includes a cold-start assertion.

- Follow-up testing reproduced two session-panel defects: collapsing a custom split left inline tracks active, and live resizing across 820px left the old grid axis and separator orientation. Collapsing now clears both axes while retaining the tab ratio. A scoped media-query listener updates the active axis, and pointer movement also checks it immediately to avoid using an old direction before the breakpoint event arrives. Regression checks keep the same SSH session and xterm instance, preserve panel focus, verify automatic terminal fitting, and exercise real pointer capture across the breakpoint.
