# 缺陷清单

[English](bug-list.md)

使用过程中发现的问题。这是一份工作清单，不是发布跟踪表；[`docs/superpowers/`](superpowers/) 下带日期的记录仍是决策的历史依据。

- [x] **Hosts 列表页面——卡片视图下的列表头。** 切到卡片视图后表头行隐藏；表格视图保留它。
- [x] **Hosts 列表页面——卡片布局。** 卡片网格按面板宽度决定列数，不再固定三列，单张卡片不会再占满三分之一宽度而右边空着。
- [x] **库页卡片——卡片内部布局。** 两张卡片视图借的都是表格的数据格 —— 主机卡片的地址、密钥卡片的指纹 —— 而那一格是卡片网格的一行，于是它落在头像底下而不是名称的左边线上：主机卡片差 72px，密钥卡片紧贴卡片左边缘。现在两者都是名称栏的一行，主机卡片的地址读作连接串，头像、名称与取值因此构成一个整体。
- [x] **切换主题颜色——终端配色。** 终端跟随主题：浅色组有自己的画布、文字颜色与 ANSI 色板，切换主题时每一块已开的终端都会重新着色。
- [ ] **缺少统一的文本说明。** 界面中英文混用，需要支持多语言国际化。
