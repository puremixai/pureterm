# 本机 Web 实施计划

Goal: 同一份 Host、协议、传输与 UI 支撑 Desktop 和独立本机 Web。
Architecture: npm workspaces；Electron 与 Node 为装配入口，Host 在各自进程内运行。
Tech stack: TypeScript、Cordis、ssh2、xterm、Electron、Node HTTP/WebSocket。
Spec: ../specs/2026-09-16-local-web.md
Global constraints: PowerShell/UTF-8；不对公网服务；不引入账号/用户隔离；Web 凭据仅本页；保留 Desktop 加密能力。

1. 抽取 packages/{protocol,host,transport,ui}，明确 package exports，建立根 workspace/lock 与按依赖顺序的构建。更新 Desktop 引用、资源定位、检查脚本及测试路径。
2. Host 单独注入 CredentialProvider；session-only 路径禁止秘密落盘，保留 Desktop 迁移兼容；增加 releaseClient 与连接期间关闭保护。先写行为测试。
3. 协议增加 RuntimeCapabilities；共享 UI 根据能力选择原生/浏览器私钥，禁用 Web 的记住凭据。先覆盖载荷与内存状态行为。
4. apps/web 添加 Node server/CLI，限制回环、提供启动 URL、完整关闭；集成验证真实 SSH/SFTP、保存、断开与退出。
5. transport 接入能力与连接回收，严格限制监听地址；Desktop 装配 safeStorage、共享资源和原有就绪状态。
6. 更新当前架构、布局说明与启动文档，运行 workspace typecheck/build、边界测试、Node 回归、Electron 启动/IPC/伴随 Web；进行独立代码评审并修复。

Host、UI 与 Web 入口是独立子任务，主 agent 负责包迁移、传输、Desktop 集成和最终验证。不在本轮自动提交推送合并。

## 实施结果（2026-09-16）

以上六项已完成，代码位于 `feat/local-web`。四个共享包与两个启动入口、根锁文件、依赖边界、当前架构和使用说明已更新。

独立评审发现并修复了跨端口 cookie 冲突、单项 smoke 未重建共享包，以及 SSH 对端不回 FIN 时 Node 退出悬挂。浏览器验收还补齐了地址栏 token 清理，并通过实际文件选择完成私钥公钥认证与终端回显。

本机 Windows 验证：根 `npm ci` 成功；`npm run verify` 通过 105 项 Node 测试及类型/边界/构建检查；`npm run verify:electron` 通过 Desktop boot、IPC、Desktop Web、独立 Node Web 浏览器四组检查。启动截图在隐藏窗口环境不可用，未计作截图验收；renderer-ready、SSH/SFTP、凭据策略和退出状态检查全部通过。未测试其他操作系统及安装包。
