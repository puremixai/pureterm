# Shared Desktop and Standalone Local Web Implementation

[中文版本](2026-09-16-local-web_zh.md)

> **Landed historical specification (2026-09-16):** This file records the standalone Web approach and its boundaries. Current runtime entry points and lifecycle are defined by the [architecture](../../architecture.md); this is no longer an unfinished task list.

The user confirmed that SSH is initiated by the user’s computer, Web is available only locally, and there is no public service or user isolation. Web does not persist passwords, private keys, or passphrases. Desktop keeps operating-system encryption and native file selection. The implementation was authorized on 2026-09-16.

The npm workspace layout is: `packages/protocol` owns the protocol and environment capabilities; `packages/host` owns Cordis/SSH/SFTP/host records; `packages/transport` owns the dispatcher and HTTP/WS; and `packages/ui` owns the shared browser UI. `apps/desktop` keeps the Electron main process, IPC, preload, and startup diagnostics and hosts shared Host in an independent Node child process. `apps/web` assembles shared Host and HTTP in an ordinary Node process.

Runtime capabilities explicitly declare credential persistence and private-key selection; do not infer them from IPC or WebSocket transport. Standalone Web uses the browser File API to read the private-key content for the current page, sends it as `privateKey` during connection, and never writes the filename as a disk path. Saving a host writes metadata only; the server also enforces the session-only policy. Desktop injects a separate safeStorage-backed `CredentialProvider`.

Standalone Web defaults to `~/.ssh-cordis/web`, while Desktop keeps `~/.ssh-cordis`, preventing two processes from overwriting each other’s host and credential files. These are entry-point data directories, not user isolation. Custom directories must not be shared while active. HTTP binds only to 127.0.0.1 and keeps the existing token and Origin/Host checks. A WebSocket close, including a handshake-time close, actively releases the SSH session it owns.

Acceptance: ordinary Node can start Web; the page and the same-protocol SSH/SFTP flows work; closing a page releases the connection; Web creates no ciphertext file and persists no private-key content; Desktop encrypted storage and IPC/attached Web do not regress; cross-package checks, existing regressions, and real Electron startup pass.
