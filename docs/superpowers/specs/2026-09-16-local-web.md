# Desktop 与本机 Web 共用实现

> **已落地的历史规格（2026-09-16）**：本文件记录本机 Web 方案及其边界。当前运行入口和生命周期以 [架构说明](../../architecture.md) 为准；本文不再作为未完成任务清单。

用户已确认：SSH 由用户电脑发起，Web 只供本机访问，不做公网服务和用户隔离；Web 暂不持久保存密码、私钥和口令。Desktop 保持系统加密及原生文件选择。2026-09-16 的“开始改吧”授权实施。

采用 npm workspaces：`packages/protocol` 管协议与环境能力，`packages/host` 管 Cordis/SSH/SFTP/主机记录，`packages/transport` 管 dispatcher 与 HTTP/WS，`packages/ui` 管同一份浏览器界面。`apps/desktop` 保留 Electron 主进程、IPC、preload、启动诊断，并通过独立 Node Host 子进程承载共享 Host；`apps/web` 用普通 Node 在自身进程内装配共享 Host 与 HTTP。

运行环境通过 capabilities 明确声明凭据保存和私钥选择能力，不能仅靠 IPC/WS 推测。独立 Web 用浏览器 File API 读取本页私钥内容，连接时发送 `privateKey`，绝不把文件名写作磁盘路径。保存主机只写元数据；服务端同样强制 session-only 策略。Desktop 通过独立 CredentialProvider 注入 safeStorage。

独立 Web 默认使用 `~/.ssh-cordis/web`，Desktop 保持 `~/.ssh-cordis`，避免两个进程整文件覆盖与密文兼容问题。这是两个启动入口的数据目录，不是用户隔离。自定义目录须避免共享一个活动目录。HTTP 只监听 127.0.0.1，保留现有 token、Origin/Host 校验。WebSocket 关闭时主动释放所属 SSH，握手期间关闭也不能留下会话。

验收：普通 Node 可启动 Web、页面及同协议 SSH/SFTP 可用、关闭页面释放连接；Web 不创建密文文件、不持久私钥内容；Desktop 加密保存和 IPC/伴随 Web 不回归；跨包依赖检查、现有回归与真实 Electron 启动均通过。
