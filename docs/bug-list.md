# Bug list

[中文版本](bug-list_zh.md)

Open issues found while using the app. This is a working checklist, not a release tracker; the dated records under [`docs/superpowers/`](superpowers/) remain the historical record of decisions.

- [ ] **Hosts page — table view keeps the list title.** When the host list is switched to table view, the list's title is still rendered; it should be hidden in that mode.
- [ ] **Hosts page — table layout.** Tighten the table so its columns stop leaving large empty areas.
- [ ] **Theme switching — terminal colors.** Under the light theme, a host's terminal background and font colors do not change.
- [ ] **No single set of UI strings.** Chinese and English are mixed across the interface. The UI needs internationalization.
